# DSH 圆屏仪表盘 — 部署指南

把 Waveshare ESP32-S3-Touch-LCD-1.85B 变成带独立 Codex 控制台和 DSH 兼容应用的桌面设备。

刷入本版本后，桌面启动器中会出现两个入口：`Codex` 是文档规划的全屏六 Agent 控制台，
`DSH` 是原有状态应用。两者共用同一个 bridge，但 UI 和生命周期彼此独立；从应用返回后回到
Waveshare Desktop 桌面。小蓝不是入口应用，而是默认常驻在桌面右下区域的动画宠物；按住它
可以拖动位置，打开全屏应用时它会随桌面自动隐藏，返回桌面后继续播放。

当前 bridge 默认连接本机 Codex app-server（`codex app-server --stdio`），不再依赖
DeepSeek Harness 的旧 HTTP API。若要兼容旧 DSH，再设置 `BRIDGE_BACKEND=dsh`。

```
┌──────────────┐     WiFi LAN      ┌──────────────┐    loopback    ┌──────────┐
│  圆屏仪表盘    │ ◄──────────────► │  Node 桥接进程  │ ◄───────────► │    DSH    │
│  (ESP32-S3)   │    WS :3082/dev   │  (bridge.js)  │  Typert RPC   │   :3080   │
└──────────────┘    token 认证      └──────────────┘               └──────────┘
```

## 第一步：跑桥接（在 DSH 所在的电脑上）

```powershell
cd D:\deepseek Harness\工作区1\dsh-esp32\bridge
npm start
```

在本仓库中运行：

```powershell
cd D:\codex\日常测试\dsh-esp32-dial\bridge
npm start
```

首次启动后打开 `http://127.0.0.1:3082/status`，应看到
`backend: "codex"`、`codexOnline: true`。Codex 桌面或 CLI 产生新 turn 后，状态会被
转换为 `working`、`thinking`、`done` 或 `error` 并转发到设备；Codex 应用会把最多 6 个会话
显示为独立 Agent 圆形按钮。

首次启动会打印：

```
bridge listening on ws://0.0.0.0:3082/dev
device token: 6c9f0c09f28d2e1135422b8fe4affc3a   ← 这个
status page: http://127.0.0.1:3082/status
```

验证：浏览器打开 `http://127.0.0.1:3082/status` 应看到 JSON（含 `dshOnline: true`）。

## 第二步：烧固件（USB 线插板子）

你**不需要**先改任何配置 —— 空白的 `Config.h` 会让首次上电直接进入配网模式。

### 装 PlatformIO

```powershell
python -m pip install platformio
```

### 编译 + 烧录

```powershell
cd D:\deepseek Harness\工作区1\dsh-esp32\firmware
pio run -t upload
```

第一次 `pio run` 会下载工具链和 LVGL 库，需要几分钟。

## 第三步：用手机配网

给板子通电。屏幕会显示：

```
  首次配置
  ┌──────────────────────┐
  │    ████████████████   │ ← WiFi QR 码
  │    ██  DSH-Dial-  ██  │   扫它加入配网 AP
  │    ██  A3B4 ██      │
  │    ████████████████   │
  │    DSH-Dial-A3B4     │
  │    7a3f1b2c           │
  │    http://192.168.4.1 │
  └──────────────────────┘
```

1. **用手机相机扫 QR 码** → 系统提示加入 WiFi `DSH-Dial-XXXX` → 确认
2. 打开浏览器，访问 `http://192.168.4.1`（iOS 接入后可能自动弹出）
3. 点"扫描"选你家 WiFi，填密码 + 桥接地址（电脑的局域网 IP）+ 第一步的 token
4. 点"保存并重启"

板子会重启，连上你家 WiFi，连上桥接，开始显示 DSH 状态。

### 以后换网络

圆屏上的**长按屏幕**会重新打开配网页面，或插 USB 用串口：

```
help       → 看命令列表
status     → 看当前配置
wifi <ssid> [password] → 改 WiFi
bridge <host> [port]    → 改桥接地址
token <token>           → 改令牌
reboot     → 重启
reset      → 恢复出厂
```

## 验证

| 动作 | 期望 |
|---|---|
| 给板子上电 | 连 WiFi → 连桥接 → 屏幕出现 DSH 当前状态 |
| 在 DSH 跑一个长任务 | 外圈进度环转动、中间显示工作状态、下方显示当前命令 |
| 等 DSH 空闲 | 屏幕变暗（60s 无活动） |
| 桥接进程停掉 | 屏幕转 ⌀ 离线态（不会假装还在工作） |
