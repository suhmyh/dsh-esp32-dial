烧完之后

板子会重启并进入配网模式：屏幕显示一个二维码和 AP 密码。

步骤做什么
1手机相机扫屏幕上的二维码 → 加入 DSH-Dial-XXXX
2浏览器打开 http://192.168.4.1
3填家里 WiFi + 电脑局域网 IP + 桥接 token
4保存重启 → 开始显示 DSH 状态

token 来自电脑上 node bridge.js 首次启动的输出。以后换网络：长按圆屏重新配网，或插 USB 用串口 help。
